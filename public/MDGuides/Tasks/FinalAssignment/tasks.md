## Τελική εργασία

### Η Σχολική Βιβλιοθήκη

Σε αυτή την τελική εργασία θα δημιουργήσεις μια μικρή βάση δεδομένων για την οργάνωση μιας σχολικής βιβλιοθήκης. Θα φτιάξεις τους πίνακες, θα εισάγεις τα δεδομένα και στη συνέχεια θα απαντήσεις σε ερωτήματα SQL.

> Στόχος είναι να δείξεις ότι μπορείς να χρησιμοποιήσεις βασικές εντολές SQL, φίλτρα, ταξινόμηση, ομαδοποίηση και σύνδεση πινάκων.

___

### Μέρος Α: Δημιουργία βάσης

#### Ερώτημα 1: Δημιουργία πινάκων

Δημιούργησε τους παρακάτω πίνακες με τις αντίστοιχες στήλες.

#### Πίνακας `students`

| Στήλη | Τι αποθηκεύει |
| --- | --- |
| `id` | μοναδικό αριθμό μαθητή |
| `first_name` | όνομα μαθητή |
| `last_name` | επώνυμο μαθητή |
| `class` | τάξη μαθητή |
| `age` | ηλικία μαθητή |

#### Πίνακας `books`

| Στήλη | Τι αποθηκεύει |
| --- | --- |
| `id` | μοναδικό αριθμό βιβλίου |
| `title` | τίτλο βιβλίου |
| `author` | συγγραφέα |
| `category` | κατηγορία βιβλίου |
| `pages` | αριθμό σελίδων |

#### Πίνακας `loans`

| Στήλη | Τι αποθηκεύει |
| --- | --- |
| `id` | μοναδικό αριθμό δανεισμού |
| `student_id` | μαθητή που δανείστηκε το βιβλίο |
| `book_id` | βιβλίο που δανείστηκε |
| `loan_date` | ημερομηνία δανεισμού |
| `return_date` | ημερομηνία επιστροφής |

### Μέρος Γ: Ερωτήματα SQL

Απάντησε στα παρακάτω ερωτήματα χρησιμοποιώντας SQL εντολές ή blocks.

| # | Δεξιότητα | Ζητούμενο |
| --- | --- | --- |
| 3 | Εμφάνιση δεδομένων | Εμφάνισε όλους τους μαθητές του πίνακα `students`. |
| 4 | Επιλογή στηλών | Εμφάνισε μόνο το όνομα, το επώνυμο και την τάξη κάθε μαθητή. |
| 5 | Φίλτρο | Εμφάνισε όλα τα βιβλία της κατηγορίας `Πληροφορική`. |
| 6 | Φίλτρο και ταξινόμηση | Εμφάνισε τα βιβλία με περισσότερες από `200` σελίδες και ταξινόμησέ τα. |
| 7 | Ομαδοποίηση | Εμφάνισε πόσα βιβλία υπάρχουν συνολικά σε κάθε κατηγορία. |
| 8 | Σύνδεση πινάκων | Για κάθε δανεισμό, εμφάνισε όνομα και επώνυμο μαθητή, τίτλο βιβλίου, κατηγορία βιβλίου και ημερομηνία δανεισμού. Ταξινόμησε τα αποτελέσματα με βάση την ημερομηνία δανεισμού. |
| 9 | Ομαδοποίηση με μαθητές | Εμφάνισε το όνομα και το επώνυμο κάθε μαθητή μαζί με το συνολικό πλήθος βιβλίων που έχει δανειστεί. |
| 10 | Σύνθετο φίλτρο με σύνδεση | Εμφάνισε το όνομα και το επώνυμο των μαθητών που έχουν δανειστεί βιβλία της κατηγορίας `Πληροφορική`, μαζί με τον τίτλο του βιβλίου. |
